# C# Programming Language

Beginner C# exercises — small console programs covering the basics of the language.

## Lessons

| Lesson | Project | What it covers |
|--------|---------|----------------|
| 01 | `lesson-01-hello-world` | `Console.WriteLine`, string concatenation |
| 02 | `lesson-02-random-order-ids` | `Random`, arrays, `for`/`foreach` loops, string formatting |
| 03 | `lesson-03-dice-roll` | `Random`, conditionals, interpolated strings |

## Run a lesson

Requires the [.NET 8 SDK](https://dotnet.microsoft.com/download).

```bash
cd lesson-01-hello-world
dotnet run
```
